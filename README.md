# Carstair Site

Affordable institutional tools for quantitative finance. Built for anyone.

## Cloudflare Pages settings

| Setting | Value |
|---------|-------|
| Framework preset | **None** |
| Build command | `npm run build` (or leave empty) |
| Build output directory | `/` or leave blank |
| Root directory | `/` |

The site is pure static HTML. The included `package.json` only exists so Cloudflare's default `npm run build` does not fail.

Repo: https://github.com/MichaelSwann2x/carstair-site
